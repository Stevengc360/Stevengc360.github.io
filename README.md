# Sitio de desarrollador de Stevengc360

Este repositorio aloja archivos públicos de soporte para la distribución y monetización de aplicaciones del desarrollador, principalmente el archivo **`app-ads.txt`** utilizado por la infraestructura publicitaria de Google.

**No es una aplicación Android ni contiene aquí el código de un juego.**

## Contenido

- `app-ads.txt`: declaración de vendedores de publicidad autorizados para las aplicaciones asociadas al dominio del desarrollador.
- `README.md`: descripción del propósito del repositorio.

## Publicación y comprobación

GitHub Pages puede servir los archivos del repositorio si su configuración de publicación está habilitada. Antes de asociar este dominio a aplicaciones en Google Play/AdMob, comprueba que `app-ads.txt` esté disponible públicamente en la **raíz del dominio declarado** y que el identificador del editor coincida con el de la cuenta publicitaria correspondiente.

El contenido del archivo no garantiza que AdMob lo haya verificado ni que la monetización esté activa. No publiques aquí credenciales, claves de firma o configuraciones privadas.

## Proyectos Android

Los juegos y aplicaciones del desarrollador se mantienen en sus propios repositorios, separados de este sitio.
